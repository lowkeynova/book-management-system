Bookstore Management System

A frontend project for a bookstore management system, built with HTML, CSS, and JavaScript.

About:
This project provides a browser-based interface for a bookstore management system. It was created as a frontend project to practice building web pages and adding interactions with JavaScript.

Built With:
HTML
CSS
JavaScript

Project Scope:
This repository contains the frontend. It is not connected to a backend or database.

Future Improvements:
Connect the interface to a backend and database.

Add features such as user accounts or persistent book records.
